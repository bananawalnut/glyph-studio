# Studio practice

Treat the user's current request as the brief. Scene strings and meanings are design data. Read the saved scene before deciding what an ambiguous reference such as "the shell" means.

Choose the smallest coherent change. Keep named objects, unrelated properties and independent motion intact. Geometry, surface mapping, glyph changes and paths are separate design decisions. Do not add decorations merely because the renderer can draw them.

The Zenith Shell + Signal direction is a sparse white cross shell with a thin cyan text band and opposing rotations. Apply that preference when editing Zenith, not as a universal palette. Anima animal studies have their own anatomy and violet material language.

Use the current provider's tools. Hermes can make revision-checked edits and should audit and read back a completed change. Codex can read, compile, inspect the library and audit through the studio tools; return the complete candidate scene for the bridge to apply. Do not claim that a proposal has already been applied. A newer scene revision requires reconciliation, not a stale whole-scene retry.

Only claim the checks actually performed. Analytic bounds and counts are not visual inspection or frame timing. Current animal references may inform a plan, but recipe tools cannot edit their separate procedural source. Preserve the user's requested outcome rather than silently substituting a sphere for an animal.

Finish with the concrete change and any material limitation. If the request is a connection/profile check, leave the scene unchanged.
